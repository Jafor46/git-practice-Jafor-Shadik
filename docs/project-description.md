## Project Description

This is a simple Python project created as part of the **Module 8 Assignment**. The program demonstrates basic Python concepts, including importing modules, creating and using functions, and displaying output on the console.

### Features

* Prints the student's name.
* Displays the current date.
* Performs basic arithmetic operations:

  * Addition
  * Subtraction
  * Multiplication
  * Division
* Uses a separate `utils.py` module to organize arithmetic functions, following good programming practices.

### Files

* `main.py` – Main program that prints the name, date, and calls the arithmetic functions.
* `utils.py` – Contains the `add()`, `subtract()`, `mul()`, and `div()` functions.
